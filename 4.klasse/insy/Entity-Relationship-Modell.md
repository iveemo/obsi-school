Entity/entität
	Ein Exemplar eines Gegenstanden, Person oder eines nicht-materiellen Gutes.
		Z.B. Schüler Meier
			DB - Software "Kundenverwaltung"

Eintitätstyp
	eine Klasse von Entitäten Z.B. SchülerIn
						-> Tabellen

Entitäten haben Eigenschaften (Attribute).
	Z.B. 
		Schülernummer
		Nachname -> Spalten der Tabellen
		Geburtsdatum

Attribute nehmen Attributwerte an
	Z.B.
		Nummerisch
		Text
		Wertebereiche Z.B. 0-16

## Relationship / Beziehungen

Entitäten können Beziheungen zueinander haben
Beziehungen können unterschiedliche Tyoen haben
	1:1
	1:n
	n:m
Beziehungen werden in immer beiden Richtungen betrachtet
