
1. ``show ip ospf interface interface``
	- zeigt die Sprecher & Stellvertreter  
	- bei Ethernet Schnittstellen (Broadcast)  
	- Sprecher / Stellvertreter wird erst gewählt, wenn es gebraucht wird  
  
1. Priorität (Standard = 1) für die Designated Router (Sprecher) Wahl bei allen Router gleich:
	- der mit der höchsten Router ID wird gewählt  
	- 0 bedeutet, dieser Router darf nicht zum Sprecher oder Stellvertreter gewählt werden  
	- wenn alle auf 0 gestellt wurden, funktioniert OSPF nicht  

## Kostenmetrik OSPF

KOSTEN = Referenzbandbreite / Schnittstellen Bandbreite  
Referenzbandbreite... auf Gerät, Standard 100.000.000 bps  
  
--> KOSTEN = 100.000.000 bps / Schnittstellen Bandbreite  

1. man nimmt die höchste existierende Bandbreite im Netzwerk als Referenzbandbreite
- ``auto-cost reference-bandwidth`` oder ``ip ospf cost``  

2. es wird immer auf den nächst höheren Integer aufgerundet (z.B. 0,1 --> 1)
